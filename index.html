从一句描述，到一首能发的歌

六个环节都是软件里现成的按钮，不需要再装编曲软件、也不需要另外找封面工具。

  • 一句话生成整首歌

    写清场景、情绪、乐器与人声质感，直接产出完整编曲与人声，不用先写词。

  • 自定义歌词

    自己写词或粘词，再配风格标签、BPM、调性、拍号与人声语言，控制得更细。

  • 参考歌词一键改写

    在软件里搜参考歌词，点一下就换成另一种说法，并逐行比对告诉你哪几行没改到。

  • 翻唱、续写、合成

    把已有片段换成新风格，或沿着结尾继续写、把几段素材融成一首。

  • 封面、歌词、LRC

    一键生成 3000×3000 封面，生成跟唱滚动歌词并导出 LRC，发布素材一次备齐。

  • 任务队列

    生成 1–3 分钟，期间可以切到别的页面继续做歌，任务中心统一看进度与结果。

常见问题

还没提到的，直接问客服。

生成一首歌要多久？怎么扣积分？

通常 1–3 分钟。每提交一次扣 30 积分，固定出 2 个版本；失败的任务不会重复扣分，可以在任务中心重试。

我完全不会写词，能用吗？

能。灵感模式只要一句描述，词和曲都由软件生成；会写词的话切到自定义歌词，可以逐句控制。

生成的歌能商用、能发到平台吗？

生成的成品可以用于你的视频、直播和音乐平台发布。但如果歌词来自参考歌词的改写，原词著作权仍属于原作者，正式商用或发行前请自行确认授权范围。

必须联网才能用吗？

生成、参考歌词、封面和更新都需要联网。已经生成好的作品、草稿和设置保存在本机，断网也能查看和播放本地音频；重新生成仍需联网。

一定要填 DeepSeek API Key 吗？

不强制。不填时，参考歌词改写使用软件内置的本地词表；填了之后会走 AI 逐行改写，改写覆盖率和语感更好。密钥只存在你本机，加密保存，不会上传。

换电脑或重装系统，作品会丢吗？

作品库、草稿存在本机用户目录，卸载时选择“保留用户数据”即可；换电脑需要用同一账号登录后重新下载已发布的作品。

支持 macOS 或手机吗？

目前只提供 Windows 10 / 11 64 位桌面版，没有 macOS 与手机端。
